# Security Policy

## Supported versions

The project is in early development and has no stable release. Security fixes are applied to `dev`, the active application development branch. Older development snapshots are not supported.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, or sensitive logs in public issues.

Email [cn.benlampson@gmail.com](mailto:cn.benlampson@gmail.com) for private vulnerability reports. You can also use GitHub's **Report a vulnerability** option in the repository's Security tab if private vulnerability reporting is available.

Include the affected revision, reproduction steps, expected impact, and a minimal example with all sensitive data removed. Allow time for investigation and remediation before public disclosure.
