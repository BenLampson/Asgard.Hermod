# Security Policy

## Supported versions

The project is in early development and has no stable release. Security fixes are applied to the current default branch. Older development snapshots are not supported.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, or sensitive logs in public issues.

Use GitHub's **Report a vulnerability** option in the repository's Security tab if private vulnerability reporting is available. Otherwise, contact the repository owner through a contact channel listed on their [GitHub profile](https://github.com/BenLampson) to arrange private disclosure.

Include the affected revision, reproduction steps, expected impact, and a minimal example with all sensitive data removed. Allow time for investigation and remediation before public disclosure.
