# Changelog

All notable changes will be documented here. Released versions will follow Semantic Versioning.

## 1.0.0 - 2026-10-17

### Added

- Windows desktop workspaces for local terminals, SSH, MySQL, PostgreSQL, Redis,
  RabbitMQ and object storage providers.
- Database queries, object browsing, execution history and guarded editing.
- Configurable AI assistance, SQL tools and SSH troubleshooting with command approval.
- English and Simplified Chinese interfaces, light and dark themes, and saved preferences.
- Optional Heimdall sign-in and encrypted configuration synchronization.
- Self-contained x64 MSIX packaging for Microsoft Store submission, including
  project licenses, third-party notices and the bilingual privacy policy.
- Desktop lifecycle, localization, keyboard, connection recovery and module regression tests.
