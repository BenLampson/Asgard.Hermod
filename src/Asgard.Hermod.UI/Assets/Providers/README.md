# Provider brand assets

These unmodified assets identify the services users connect to. They are embedded
as WPF resources in `Asgard.Hermod.UI`; displaying them performs no network request.
The names and marks belong to their respective owners. Their inclusion does not
imply endorsement of Hermod, and the project's Apache license does not grant
rights to third-party trademarks.

The Alibaba Cloud, Tencent Cloud and Volcengine images identify the provider;
the AWS asset identifies S3 specifically. MinIO's [trademark policy](https://www.min.io/legal/trademark-policy)
applies to its mark. The generic S3-compatible connector uses the existing generic
cloud icon rather than another provider's brand.
