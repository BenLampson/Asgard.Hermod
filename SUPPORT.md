# Support

Asgard Hermod is a Windows desktop tool for developers and operators. A Hermod
account is optional for local and remote resource management. Signing in and
setting a synchronization password enable cross-device configuration sync.

## Contact

- Project website: <https://github.com/BenLampson/Asgard.Hermod>.
- Bugs and feature requests: <https://github.com/BenLampson/Asgard.Hermod/issues>.
- Support email: [cn.benlampson@gmail.com](mailto:cn.benlampson@gmail.com).
- Privacy inquiries and account or cloud data deletion requests:
  [cn.benlampson@gmail.com](mailto:cn.benlampson@gmail.com). See the
  [Privacy Policy](PRIVACY.md) for data handling details.
- Vulnerabilities: follow [SECURITY.md](SECURITY.md) and contact us privately.

## Reporting a problem

Include the Hermod version, Windows version, affected workspace type, steps to
reproduce, expected behavior and actual behavior. Provide the localized error
shown by the application and a minimal, redacted example when available.

Do not post passwords, private keys, API keys, authentication tokens, connection
strings or private server addresses in a public issue. Remove private records and
credentials from screenshots and logs before sharing them.
